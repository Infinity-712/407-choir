# 407 · 合唱小屋

可爱角色 + 已还原的合唱室，独立于 `../demo` 的可运行网页项目。

## 启动

已安装依赖。双击 **启动小屋.cmd**，或在此目录运行：

```powershell
npm run build
npm start
```

浏览器打开 **http://localhost:3001**。保持服务窗口开启即可游玩，关闭窗口停止服务。开发模式用 `npm run dev`，前端 http://localhost:5173。

## 已实现

- 三维捏脸：肤色、发型/发色、衣服/裤色、配饰、脸宽、眼睛大小和间距、嘴型、腮红；随机造型、拖动预览、本地保存，入房后也可换装。
- 真实房间 GLB，来自 20260930 v3 场景：56 把可坐椅子、3 架可弹立式钢琴和 1 架可弹电钢琴、指挥位置；沿用源场景钟表下方的中央通道与八顶点房间轮廓。
- 自制角色走动、转向、坐姿、钢琴/指挥姿势、眨眼呼吸、挥手/鼓掌/比心。
- 点击地面或物件寻路；WASD/方向键移动、Shift 加速、拖动视角/滚轮缩放、E 互动、Esc 退出。中央通道可连续上下四层台阶。
- 手机左侧摇杆移动，滑动画面转视角，双指缩放；点「地点」导航、点互动按钮坐下或起身。横竖屏、安全区、大尺寸按钮均已适配，触屏设备默认流畅画质。
- Socket.IO 多人同步、独占物件、房间号隔离、断线清音/释放占用。每房间保护上限 16 人，实际部署人数需要设备/网络压测。
- 钢琴：电脑24键、手机12个较大琴键，八度切换覆盖88键范围；键盘/鼠标/多指触屏演奏，空格或触屏延音；独立琴键动画、合成琴声、全房间音符事件。
- 指挥：二拍、三拍、四拍，起拍、收拍、渐强、渐弱手势；全员同步动作与40–200 BPM节拍。
- 合唱姿势：左臂、右臂、双臂缓缓抬起并保持，以及左手抚右胸、右手抚左胸。工具栏「表情动作」选择，再点同一姿势放下，也可「恢复姿势」。走动或坐下仍保持，短暂表情结束后恢复；弹琴或指挥时让出双手。
- 头顶聊天：点「聊天」或按Enter打开，最多80个Unicode码点，Enter发送、Shift+Enter换行。文字/8个快捷emoji在名字上方显示8秒，同一房间可见；只保留每人最新一条，不保存聊天记录。4种配色与圆角/云朵气泡，样式在当前浏览器记忆。输入时暂停走动和琴键快捷键，Esc先关闭输入框。
- 近距离实时人声：1.5米内清晰，逐渐衰减至9米外静音，左右方位跟随视角。默认语音音量55%，开启回声消除/降噪，关闭自动增益，使用高通、柔和噪声门和压限。
- 麦克风默认关闭；进入钢琴演奏时关闭本人麦克风，别人可继续说话；退出不会自动开麦。独立语音/琴声音量、单人本地静音和发言提示。「声音与画质」可调麦克风灵敏度：底噪大时调低，轻声听不清时调高。

## 真实联网

同一台电脑可开两个浏览器窗口测试多人。其他设备需要访问运行服务器的电脑地址，且网络允许连接该端口。

手机和电脑连接同一Wi-Fi后，打开 `http://电脑局域网IPv4地址:3001`。本次环境地址是 `http://10.15.175.106:3001`（更换网络后可能变化）。此地址可游玩、弹琴、收听；手机开麦需要可信HTTPS地址。

**正式公网麦克风需要 HTTPS 和可用的 WebRTC 网络连接。** 本地 `localhost` 可使用麦克风；普通局域网 HTTP 地址通常无法申请麦克风。当前语音是适合小房间的 WebRTC 点对点连接，附带 STUN；不同运营商、严格 NAT 或企业网络通常还需要 TURN 中继。实际跨设备/公网听感尚须现场联调。游戏服务器和 WebSocket 需要持续运行，不能只把静态页面上传到普通静态空间。

设置 `ICE_SERVERS` JSON 可配置自己的中继，格式见 `.env.example`。本项目不自动读取 `.env`，请由运行环境设置变量。TURN 必须使用专门发给客户端的短期凭据；不要把服务器管理密钥放在这里。扩大语音人数时建议替换成 SFU 服务，游戏状态服务可沿用。

音频适合聊天、听琴和节拍提示；网络延迟决定它不能等同于同地同步合唱。首版琴声是程序合成音色，可后续替换为高品质钢琴采样。

## 文件

| 文件 | 内容 |
| --- | --- |
| `public/assets/room.glb` | 从已验收场景导出的压缩房间 |
| `public/assets/interaction-layout.json` | 坐点、互动编号、碰撞、台阶；米制 Y-up |
| `public/assets/export-report.json` | 导出指标及源文件未变的 SHA256 |
| `scripts/export_room.py` | 可重跑的 Blender 后台导出 |
| `src/avatar` / `src/components/AvatarEditor.tsx` | 自制角色与捏脸面板 |
| `src/scene/RoomWorld.ts` | 渲染、角色、输入、寻路 |
| `src/audio` | 钢琴合成与实时语音 |
| `server` / `shared` | 多人权威状态与公共协议 |
| `artifacts` | 浏览器验收截图 |

后续补拍修改模型时保留资产 ID 和定位点，重新导出房间即可继续使用交互。新增钢琴需增加独立资产 ID、琴键 MIDI 属性与互动位置。

## 资产与来源

角色为本项目自制参数几何；房间源自用户的本地 Blender 场景 `../demo/revision_20260930_v3/407_choir_photo_revision_v3.blend`。导出遵循场景的渲染可见性与归档排除设置，保留修正后的椅背支撑及柜顶陈列。为了让四台乐器都能使用，网页副本移动了电钢琴与原黑色钢琴琴凳，并为第三架立式钢琴和电钢琴各增加一张琴凳；这些调整仅发生在导出进程中，不保存或修改源 `.blend`，导出报告记录源文件 SHA256。木纹为程序生成纹理，没有参考照片投射。未使用第三方角色素材。依赖及本地 Draco 解码器遵循各自软件许可证。

实现参考：[Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)、[Socket.IO 房间](https://socket.io/docs/v4/rooms/)、[MDN 麦克风权限](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[MDN WebRTC](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API)。

空间语音参考：[Simple Voice Chat 距离设置](https://modrepo.de/minecraft/voicechat/wiki/server_config)、[Web Audio PannerNode](https://developer.mozilla.org/en-US/docs/Web/API/PannerNode)。本项目的1.5–9米范围按室内尺寸选定，不照搬Minecraft的距离值。
